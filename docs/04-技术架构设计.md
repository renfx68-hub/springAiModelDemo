# 辣条log · 技术架构设计

版本 v0.2 ｜ 2026-11-13

## 1. 总体架构（现状 + 演进）

```
┌─────────────────────────── 浏览器（原生 JS SPA）───────────────────────────┐
│  会话管理 / SSE 流式解析 / Markdown(DOMPurify) / 图片上传预览 / 画画模式     │
└───────────────┬─────────────────────────────────────────────────────────┘
                │ REST + SSE (fetch + ReadableStream)
┌───────────────▼──────────── Spring Boot 3.4 后端 ─────────────────────────┐
│ Controller 层   Chat / Session / Image(访问+生成)                          │
│ Service 层      ChatService(多模态流式)  SessionService  ImageGeneration    │
│                 ImageStorageService(上传/生成结果落盘)                      │
│ 配置层          ChatSettings / ImageSettings / Dotenv(.env 自动加载)        │
│ 数据层          Spring Data JPA → H2(默认) / MySQL(docker profile)          │
└───────────────┬─────────────────────────────────────────────────────────┘
                │ OpenAI 兼容 HTTP（可切换厂商）
┌───────────────▼──────────────────────────────────────────────────────────┐
│ 智谱 GLM：glm-5.3-flash(对话)  glm-4.5v(视觉)  cogview-3-flash(文生图)      │
│ 备选：DeepSeek / 通义 / Kimi / OpenAI / Ollama                              │
└──────────────────────────────────────────────────────────────────────────┘
```

## 2. 技术选型与理由

| 层 | 选型 | 理由 |
|---|---|---|
| 后端框架 | Spring Boot 3.4 + JDK 21 | 生态成熟、Spring AI 一等支持 |
| 模型接入 | Spring AI 1.0（OpenAI 兼容） | 多模态消息原生支持；换厂商只改配置 |
| 流式 | SSE（Flux + WebFlux 传递依赖） | HTTP 原生、前端 EventSource 友好（POST 场景用 fetch 流解析） |
| 前端 | 零框架 + 本地 vendor（marked/hljs/DOMPurify） | 零构建、可离线、无 CDN 依赖 |
| 存储 | H2 文件库 → MySQL | 起步零安装，规模化了平滑迁移 |
| 部署 | Dockerfile（多阶段）+ compose | 一条命令起服务，mysql profile 可选 |

## 3. 关键设计决策

1. **厂商可替换**：全部能力走 OpenAI 兼容协议或独立配置（`OPENAI_*` 系列环境变量）；换厂商不改代码。
2. **密钥治理**：`.env` 本地文件（gitignore）+ `EnvironmentPostProcessor` 自动加载；仓库永不含 Key。
3. **图片资产本地化**：上传与生成图片均落 `data/uploads/`，DB 存相对 URL——避免外链过期。
4. **断连不丢**：SSE 取消时（`doOnCancel`）异步落库已生成部分。
5. **上下文策略**：按轮次裁剪（默认 12 轮），带图历史重建媒体再入上下文。

## 4. 演进架构（后续迭代引入）

| 能力 | 引入组件 | 说明 |
|---|---|---|
| 联网搜索 | 智谱 web_search tool / 博查 API | 走工具调用机制 |
| 语音 | ASR/TTS 接口 + 浏览器 MediaRecorder | 音频落 uploads |
| 知识库 RAG | 文档解析(PDFBox/POI) + Embedding + 向量库 | 起步可用 H2 存向量简化实现 |
| 智能体 | Spring AI Function Calling + 工具注册中心 | 与搜索共用机制 |
| 多用户 | Spring Security + 账号表 + 数据隔离 | 上线前必做 |
| 可观测 | Micrometer + 日志文件 + 健康检查 | 已有 actuator/health 基础 |

## 5. 容量与性能预估（单实例）

| 指标 | 预估 |
|---|---|
| 并发流式会话 | 20~50（受厂商 API 限流约束） |
| H2 单文件库 | <2GB 无压力（约百万级消息） |
| 图片存储 | uploads 目录按需扩容/挂卷 |
