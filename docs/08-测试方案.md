# 辣条log · 测试方案

版本 v0.2 ｜ 2026-11-13

## 1. 测试策略（金字塔）

| 层级 | 工具 | 范围 | 门槛 |
|---|---|---|---|
| 单元测试 | JUnit5 + Mockito | 服务逻辑（裁剪、参数钳制） | `mvn test` 全绿 |
| 集成/契约测试 | @WebMvcTest / MockMVC | 接口契约（SSE 事件结构、状态码） | 同上 |
| 端到端自测 | 脚本（Invoke-RestMethod/curl） | 真实厂商 API 链路 | 每个功能上线前跑一遍 |
| 手工验收 | 浏览器 | 交互、视觉、体验 | 清单全绿才发版 |

现有测试基线：`ContextTrimmingTest`（裁剪逻辑）、`ChatControllerTest`（SSE 契约，2/2 绿）。

## 2. 已完成用例 ✅

- 上下文裁剪：N 轮正序保留 / 不足全量 / 非法 historyRounds 钳制

## 4. S2 图片生成用例 🚧

| 用例 | 预期 |
|---|---|
| 正常生成 | 返回助手消息含 imageUrl；图片 GET 200；两条消息（user+assistant）落库 |
| 未配 Key | 400 + 明确提示 |
| 模型名错误/厂商失败 | 502 + 可读错误，不落库 |
| 生成结果下载失败 | 502 + 可读错误，不落库 |
| prompt 超长/为空 | 400 校验拦截 |
| 真实生成耗时 | ≤15s（cogview-3-flash） |

## 5. 手工验收清单（每个发版必过）

1. 新建会话 → 发文字 → 流式输出 → 停止生成 → 已生成部分保留
2. 刷新页面 → 历史与列表恢复（含图片）
3. 重命名/删除会话生效
4. 代码块高亮与复制可用
5. 移动端宽度（≤860px）侧边栏抽屉可开合
6. 控制台无 JS 报错

## 6. 已知测试注意事项

1. 测试断言避免中文字面量（控制台编码差异），用 ASCII 结构断言。
2. 命令行 curl 发中文 JSON 有编码坑，自测脚本用 UTF-8 字节体（Invoke-RestMethod）。
3. 真实厂商调用受网络/限流影响，E2E 失败先看服务端日志再重试一次再定性。
