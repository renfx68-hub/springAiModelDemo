# 辣条log · 产品需求文档（PRD）

版本 v0.2 ｜ 负责人：产品 & 开发 ｜ 更新日期：2026-11-13

## 1. 产品概述

- **产品名**：辣条log（LatiaoLog）
- **一句话定位**：一根辣条成精的 AI 助手——像豆包一样全能（聊天/看图/画画/语音/搜索），但更年轻、更玩梗、更有陪伴感。
- **产品人格**：吉祥物"辣条"是一根拟人化的辣条，性格热情上头、嘴硬心软、偶尔无厘头；自称"辣条"，称用户"老板"。
- **Slogan**：「有点上头的 AI 助手」
- **载体**：Web 网页（后续 PWA 化支持手机桌面图标）。

## 2. 目标用户与场景

| 用户群 | 典型场景 | 诉求 |
|---|---|---|
| 学生党 | 拍题看解析、写周报文案、查资料 | 免费/便宜、答得快、会玩梗 |
| 年轻打工人 | 生成表情包/头像、闲聊解压、起名起标题 | 有趣、有陪伴感、随手可用 |
| 轻度尝鲜用户 | 替代豆包/Kimi 的第二选择 | 开箱即用、不用注册门槛低 |

## 4. 功能需求（按优先级）

### P0 —— 已实现 ✅
| 功能 | 描述 | 验收标准 |
|---|---|---|
| 文字对话 | 打字机流式输出，多轮上下文 | 发送后 2s 内出首字；中断后已生成部分保留 |
| 会话管理 | 新建/重命名/删除，自动命名 | 刷新后列表与历史完整恢复 |
| 富文本渲染 | Markdown + 代码高亮 + 复制 | 代码块一键复制；无 XSS |
| 图片识别（看图说话） | 📎 上传/Ctrl+V 粘贴，自动切视觉模型 | 支持/png/jpg/webp/gif ≤8MB；可对同一图追问 |
| 一键换厂商 | 环境变量切换 base-url/model | 改配置不改代码即可切换 |

### P1 —— 进行中/近期 🚧
| 功能 | 描述 | 验收标准 | 状态 |
|---|---|---|---|
| 图片生成 | 🎨 画画模式，输入描述出图，可下载 | 15s 内返回；图落本地可访问；历史可回看 | 🚧 后端完成，前端开发中 |

| 语音播报 | 回答可朗读 | 支持播放/暂停 | 📋 |

## 5. 非功能需求

| 维度 | 要求 |
|---|---|
| 性能 | 首字延迟 ≤2s；会话列表加载 ≤500ms；图片接口 ≤15s |
| 可用性 | 单实例可用性 ≥99%（个人/小规模阶段） |
| 安全 | Key 不入库不入仓库；XSS 过滤；上传类型与大小校验；路径穿越防护 |
| 成本 | 默认免费额度模型（glm-5.3-flash 聊天 / cogview-3-flash 画图）；用量可在配置切换 |
| 兼容 | Chrome/Edge 最新两个大版本；移动端 ≤860px 抽屉布局 |

## 6. 成功指标（北极星：周活跃会话数）

- 次周留存 ≥30%；平均单会话消息数 ≥6；图片功能周使用率 ≥15%。
