## 2. 我们打得过什么、打不过什么

**打得过（差异化）**
1. **人格陪伴感**：豆包 IP 偏官方，辣条可以更接地气（零食梗、打工人共鸣）。
2. **可自部署 + 模型可换**：极客/学生可自己部署，成本可控；竞品做不到。
3. **迭代速度**：小产品船小掉头快，功能紧跟豆包补齐。

**打不过（不硬碰）**
1. 底层模型能力（我们靠 API，不追平训练能力）。
2. 多端生态（抖音/飞书联动等）。

## 3. 对产品决策的输入

1. 人设是第一优先级资产：系统提示词、欢迎语、空态文案、错误文案全部人格化（见 03 设计规范）。
2. 功能对齐节奏：跟豆包补齐 P1 清单，不自研模型能力。
3. 留「专业模式」开关：人设梗不影响查资料、写代码时的准确性。
