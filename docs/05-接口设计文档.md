# 辣条log · 接口设计文档（API）

版本 v0.3 ｜ 2026-11-13 ｜ 基础路径 `http://localhost:8080`

通用约定：请求/响应均为 JSON（UTF-8）；错误返回结构由 `GlobalExceptionHandler` 统一为
`{"code":"...","message":"..."}`；流式接口用 SSE，事件名 `delta` / `done` / `error`。

## 1. 已实现接口 ✅

### 1.1 会话
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/sessions` | 会话列表（按更新时间倒序） |
| POST | `/api/sessions` | 创建会话 `{title}`，返回 201 |
| GET | `/api/sessions/{id}` | 会话详情含 `messages[]`（含 `imageUrl`） |
| PATCH | `/api/sessions/{id}` | 重命名 `{title}` |
| DELETE | `/api/sessions/{id}` | 删除会话及消息，204 |

### 1.2 对话（SSE 流式）
`POST /api/chat/stream`
```json
{ "sessionId": "uuid", "message": "文本(≤20000)", "imageBase64": "可选, data:image/png;base64,... 或纯 base64, ≤8MB" }
```
SSE 事件：
```
event:delta  data:{"type":"delta","content":"…"}
event:done   data:{"type":"done", …}
event:error  data:{"type":"error","code":"API_KEY_MISSING|…","message":"…"}
```
行为：带 `imageBase64` 时自动切视觉模型并落盘图片；断连时已生成部分落库。

### 1.3 图片
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/images/{name}` | 读取本地图片（UUID 文件名，30 天浏览器缓存） |
| POST | `/api/images/generate` | 🚧 文生图：`{sessionId, prompt(≤2000)}` → 助手消息（含 `imageUrl`），同步返回（约 5~15s） |

### 1.4 其他
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/actuator/health` | 健康检查（仅暴露 health） |

## 3. 变更纪律

1. 已实现接口的字段**只增不改不删**；破坏性变更需升版本号（`/api/v2/...`）。
2. 每个 Sprint 的接口变更同步更新本文与前端契约测试。
