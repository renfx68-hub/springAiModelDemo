# 辣条log · 接口设计文档（API）

版本 v0.3 ｜ 2026-11-13 ｜ 基础路径 `http://localhost:8080`

通用约定：请求/响应均为 JSON（UTF-8）；错误返回结构由 `GlobalExceptionHandler` 统一为
`{"code":"...","message":"..."}`；流式接口用 SSE，事件名 `delta` / `done` / `error`。

## 1. 已实现接口 ✅

### 1.1 会话
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/sessions` | 会话列表（按更新时间倒序） |
| POST | `/api/sessions` | 创建会话 `{title}`，返回 201 |
| GET | `/api/sessions/{id}` | 会话详情含 `messages[]`（含 `imageUrl`） |
| PATCH | `/api/sessions/{id}` | 重命名 `{title}` |
| DELETE | `/api/sessions/{id}` | 删除会话及消息，204 |

### 1.2 对话（SSE 流式）
`POST /api/chat/stream`
```json
{ "sessionId": "uuid", "message": "文本(≤20000)", "imageBase64": "可选, data:image/png;base64,... 或纯 base64, ≤8MB", "professional": "可选布尔，专业模式", "legal": "可选布尔，法律模式" }
```
SSE 事件：
```
event:delta  data:{"type":"delta","content":"…"}
event:done   data:{"type":"done", …}
event:error  data:{"type":"error","code":"API_KEY_MISSING|…","message":"…"}
```
行为：带 `imageBase64` 时自动切视觉模型并落盘图片；断连时已生成部分落库。
提示词优先级：`legal=true` > `professional=true` > 默认辣条人设（前端两开关互斥）。

### 1.4 语音
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/voice/transcribe` | 语音转文字：multipart `file`（WAV/MP3，≤20MB，建议 ≤60s）→ `{text}`；内部调 `app.voice.transcriptions-path`（默认 glm-asr） |
| POST | `/api/voice/speak` | 文本转语音：`{text(≤2000)}` → 音频字节流（audio/wav 或厂商返回类型）；默认 glm-tts + voice `tongtong` |

> 契约说明：厂商额度不足（402/429，智谱错误码 1113）时返回 502 + 明确提示；前端优先使用浏览器原生语音能力，后端接口作为兜底通道。

### 1.5 账号（邮箱注册登录，2026-11-16 已实现）
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/auth/register` | `{email, password(8~72), nickname?, code?}` → `{token, user}`；邮箱重复返回 409；首个注册用户自动接管历史无主会话。**开启邮件服务时 `code` 必填**（见下方验证码） |
| POST | `/api/auth/login` | `{email, password}` → `{token, user}`；邮箱大小写不敏感，失败统一 401「邮箱或密码不正确」 |
| GET | `/api/auth/capabilities` | `{mailEnabled, devMode}`；前端据此决定是否展示验证码输入与"忘记密码" |
| POST | `/api/auth/code` | 发送邮箱验证码 `{email, purpose: register|reset}` → `{sent, devCode?}`；同一邮箱 60s 内不可重发（429）。`devCode` 仅开发模式（`APP_MAIL_DEV_MODE=true`）回传 |
| POST | `/api/auth/reset` | 忘记密码 `{email, code(6位), newPassword(8~72)}` → 204；验证码错误/过期 400，次数超限 429 |
| GET | `/api/auth/me` | 当前用户（需 Bearer token） |
| POST | `/api/auth/logout` | 204；无状态 token，由前端丢弃凭证 |

邮箱验证码约定（SMTP，2026-11-16 已实现，默认 QQ 邮箱）：
1. 配置 `APP_MAIL_ENABLED=true` + `APP_MAIL_USERNAME`（QQ 邮箱地址）+ `APP_MAIL_PASSWORD`（**授权码**，非登录密码）后生效
2. 验证码 6 位数字、10 分钟有效、60 秒重发间隔、连续错 5 次作废；存内存（重启失效），多实例部署需换 Redis
3. 未配置邮件时**自动降级**：注册免验证码，`/api/auth/code` 返回 503，"忘记密码"入口隐藏
4. `purpose=reset` 对不存在的邮箱也返回成功（防邮箱枚举），但不真正发信
5. 开发模式 `APP_MAIL_DEV_MODE=true`：不发真实邮件，验证码写日志并由接口回传，**仅限本地联调**

鉴权约定：
1. 除 `/api/auth/register|login|code|reset|capabilities` 与 `/api/images/**`（`<img>` 无法带请求头）外，所有 `/api/**` 需要 `Authorization: Bearer <token>`
2. token 为自签 HS256，默认 7 天有效期（`APP_AUTH_TOKEN_HOURS`），密钥 `APP_AUTH_SECRET`（生产必须覆盖默认值）
3. 会话/消息按 `owner_id` 隔离，非本人会话一律 404（不泄露存在性）

### 1.6 美股行情连接器（2026-11-16 已实现）
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/market/quotes?symbols=IXIC,DJI,INX` | 返回指数/个股实时报价；不传 `symbols` 默认三大指数。数据源腾讯财经，20 秒缓存 |

返回字段：`symbol, name, code, price, change, changePercent, open, previousClose, high, low, currency, time`

约定：
1. 聊天时由后端识别意图（"纳斯达克 / 纳指 / 道指 / 标普 / 美股行情 / 个股中文名 / 大写代码如 AAPL"），命中后把报价作为 SystemMessage 注入，模型必须引用真实数字并标注数据时间
2. 未命中意图不发起外部请求；抓取失败静默降级（回退上一次缓存），不影响聊天
3. 数据仅供参考、不构成投资建议（注入文本中已明确要求模型提示用户）
4. 可配置：`APP_MARKET_ENABLED=false` 关闭，`APP_MARKET_BASE_URL` 更换数据源

## 3. 变更纪律

1. 已实现接口的字段**只增不改不删**；破坏性变更需升版本号（`/api/v2/...`）。
2. 每个 Sprint 的接口变更同步更新本文与前端契约测试。
