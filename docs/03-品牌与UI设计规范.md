# 辣条log · 品牌与 UI 设计规范

版本 v0.1 ｜ 2026-11-13

## 1. 吉祥物设定：辣条

| 项 | 设定 |
|---|---|
| 身份 | 一根成精的辣条（拟人，长条身体 + 辣椒表情 + 略微油光） |
| 性格 | 热情上头、嘴硬心软、偶尔无厘头；专业问题秒变靠谱 |
| 自称 | 辣条（本辣条/辣条我） |
| 对用户称呼 | 老板 |
| 口头禅 | 「包的」「辣味管够」「嗷呜」 |
| 禁忌 | 不装可怜卖惨、不低俗、不阴阳怪气 |

**形象使用**：聊天头像（✦ 占位，后续换 SVG 吉祥物）、欢迎页空态插画、错误提示、加载动画（辣条扭动）。

## 2. 色板（从"辣条包装"提取）

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 辣条红 | `#E4392E` | 品牌标识、发送按钮、强调（替代现有紫色 `#a78bfa`） |
| 辅色 辣油橙 | `#F5A623` | 高亮、加载动画、光标 |
| 辅色 辣椒绿 | `#3E8E5A` | 成功状态 |
| 中性 深底 | `#111318` / 面板 `#191b22`（现状保留） | 深色主题基底 |
| 中性 文字 | `#e7e9ee` 主 / `#9399a8` 次（现状保留） | |

> 迁移成本低：现有 CSS 变量 `--accent` 一处替换即可完成主色切换。

## 3. 文案调性（Voice & Tone）

- **正常对话**：活泼但准确；每条回复最多一个梗，不喧宾夺主。
- **空态欢迎语**：「老板来啦！辣条在的，想聊点啥？可以让我看图、画画，也可以直接开吹 🌶️」
- **加载中**：「辣条在疯狂输出中…🌶️」
- **错误提示**：先道歉+再指路。例：「嗷呜，辣条被辣到了（接口报错）。老板再试一次，或换个说法？」
- **专业模式开启时**：去掉梗，只留准确与效率。

## 4. 组件规范

| 组件 | 规范 |
|---|---|
| 消息气泡 | 用户右侧灰底、助手左侧深底；头像 30px 圆角方块 |
| 图片气泡 | 圆角 10px、最大宽 340px、点击放大（规划） |
| 按钮 | 主按钮红底白字圆角 8px；图标按钮 34px 方形 |
| 打字光标 | `▍` 动画，颜色用辣油橙 |
| 代码块 | 深底 + atom-one-dark，右上复制按钮 |

## 5. 交互原则

1. 流式优先：一切生成类内容逐字/渐进呈现。
2. 可中断：生成中可「停止生成」，已生成部分保留。
3. 状态可见：上传/生成过程必须有进度或动画反馈。
4. 失败可重试：错误提示附重试入口。
