# 辣条log · 品牌与 UI 设计规范

版本 v0.1 ｜ 2026-11-13

## 1. 吉祥物设定：辣条

| 项 | 设定 |
|---|---|
| 身份 | 一根成精的辣条（拟人，长条身体 + 辣椒表情 + 略微油光） |
| 性格 | 热情上头、嘴硬心软、偶尔无厘头；专业问题秒变靠谱 |
| 自称 | 辣条（本辣条/辣条我） |
| 对用户称呼 | 老板 |
| 口头禅 | 「包的」「辣味管够」「嗷呜」 |
| 禁忌 | 不装可怜卖惨、不低俗、不阴阳怪气 |

**形象使用**：聊天头像（✦ 占位，后续换 SVG 吉祥物）、欢迎页空态插画、错误提示、加载动画（辣条扭动）。

## 2.5 双主题（白天 / 夜间）

全套颜色已变量化，以 `html[data-theme]` 切换，两套色板如下：

| 变量 | 夜间（默认） | 白天 |
|---|---|---|
| `--bg` / `--bg-elevated` / `--panel` | `#111318` / `#17191f` / `#1c1e25` | `#faf7f4` / `#f2ece7` / `#ffffff` |
| `--text` / `--text-secondary` / `--text-dim` | `#e7e9ee` / `#c4c7d0` / `#9399a8` | `#221d1a` / `#4a423d` / `#7d726b` |
| `--border` / `--border-strong` | `#2b2e38` / `#3a3d48` | `#e6dbd3` / `#d6c8bf` |
| `--accent` | `#e4392e` | `#d9342a`（略深，保证对比度） |

规则：
1. 首次访问跟随系统 `prefers-color-scheme`；用户手动切换后存 `localStorage(latiao-theme)`，优先级高于系统
2. `<head>` 内联脚本在样式加载前应用主题，避免首屏闪烁
3. **代码块在两种主题下均保持深色**（GitHub Dark 高亮），保证 token 可读
4. 白天模式用暖白"辣条纸感"（略带米色），避免纯白刺眼；辣条红在浅底上加深为 `#d9342a`

## 3. 文案调性（Voice & Tone）

- **正常对话**：活泼但准确；每条回复最多一个梗，不喧宾夺主。
- **空态欢迎语**：「老板来啦！辣条在的，想聊点啥？可以让我看图、画画，也可以直接开吹 🌶️」
- **加载中**：「辣条在疯狂输出中…🌶️」
- **错误提示**：先道歉+再指路。例：「嗷呜，辣条被辣到了（接口报错）。老板再试一次，或换个说法？」
- **专业模式开启时**：去掉梗，只留准确与效率。

## 4. 组件规范

| 组件 | 规范 |
|---|---|
| 消息气泡 | 用户右侧灰底、助手左侧深底；头像 30px 圆角方块 |
| 图片气泡 | 圆角 10px、最大宽 340px、点击放大（规划） |
| 按钮 | 主按钮红底白字圆角 8px；图标按钮 34px 方形 |
| 打字光标 | `▍` 动画，颜色用辣油橙 |
| 代码块 | 深底 + atom-one-dark，右上复制按钮 |

## 5. 交互原则

1. 流式优先：一切生成类内容逐字/渐进呈现。
2. 可中断：生成中可「停止生成」，已生成部分保留。
3. 状态可见：上传/生成过程必须有进度或动画反馈。
4. 失败可重试：错误提示附重试入口。
